# Registro de cambios

## 0.4.0-rc.1 — Base colaborativa de Sumativa 4

- Base híbrida ejecutable con Ionic 9, React 19 y TypeScript.
- Login e inicio demostrativos con sesión local sin almacenar contraseñas.
- Dominio, repositorio versionado en `localStorage`, proveedor de estado y validaciones comunes.
- Trece pruebas móviles, lint y compilación configurados.
- Esqueletos navegables de captura e histórico preparados para integración.
- CI móvil y configuración monorepo preparada para AWS Amplify.
- Contrato técnico, plan de integración neutral y ADR.

Esta versión es una candidata de base: no incluye API, sincronización remota,
despliegue AWS ni módulos funcionales completos de captura e histórico.

## 0.3.0 — Sumativa 3

- Copia pública y sanitizada del MVP web verificado.
- Mockup móvil navegable con siete pantallas y datos ficticios.
- Documentación de la integración móvil/web como evolución futura.
- CI para 57 pruebas Django y 9 pruebas estructurales del mockup.
- Publicación automatizada mediante GitHub Pages.
- Evidencias visuales y reproducción comprobada desde clon limpio.

## 0.1.1 — Base verificada

- CRUD Django de novedades, borradores, fotografías, histórico y estados.
- Catálogos configurables, autenticación, permisos y pruebas automatizadas.
- Transferencia portable de datos para administración local.
